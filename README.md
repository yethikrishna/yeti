## Overview

**Yeti** is the core repository of the Yeti AI ecosystem by [yethikrishna](https://github.com/yethikrishna). This project serves as the foundation for a family of AI platforms including [YetiAI](https://github.com/yethikrishna/yetiai), [YetiVerse Hub](https://github.com/yethikrishna/yetiverse-hub), [Yeti Suna AI](https://github.com/yethikrishna/yeti-suna-ai), [YetiChat AI](https://github.com/yethikrishna/yetichat-ai), and the [YetiVerse Connector Hub](https://github.com/yethikrishna/yeti-verse-connector-hub).

## The Yeti AI Ecosystem

| Repository | Description |
|---|---|
| [yetiai](https://github.com/yethikrishna/yetiai) | Core AI platform with React, Vite, Supabase, Clerk |
| [yeti-ai](https://github.com/yethikrishna/yeti-ai) | Full-stack AI app platform (Python backend + React/Vite) |
| [yeti-suna-ai](https://github.com/yethikrishna/yeti-suna-ai) | Suna-based autonomous AI assistant fork |
| [yetiverse-hub](https://github.com/yethikrishna/yetiverse-hub) | Central hub for the YetiVerse ecosystem |
| [yeti-verse-connector-hub](https://github.com/yethikrishna/yeti-verse-connector-hub) | Integration hub connecting all Yeti platforms |
| [yetichat-ai](https://github.com/yethikrishna/yetichat-ai) | AI research assistant with Google Gemini + LangGraph |
| [yetr-ai-agent](https://github.com/yethikrishna/yetr-ai-agent) | Enhanced MCP task runner for autonomous workflows |
